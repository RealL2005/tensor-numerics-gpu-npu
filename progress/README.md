# 每日进度

每天一个文件：`progress/YYYY-MM-DD.md`，新建用 `bash scripts/new_day.sh`（自动填日期并更新下方索引）。

## 记录原则

- **一句话说清今天推进了什么**，不要写流水账。
- **当天产生的数字要能回溯**：写清是哪个输入、哪台设备、什么配置、产物在哪。
- **卡点单独写**：卡住的地方往往是第二天/后续选题的线索。
- **不确定的结论标注「待验证」**，不要因为「看起来有规律」就下结论。
